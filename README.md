# TurnDown-OneLiner

A minimal HTML-to-Markdown converter in a single HTML file.

## Usage

1. Open the page in a browser
2. Enter HTML when prompted
3. View the converted Markdown in the page and copy from the prompt

## How It Works

Uses the [TurnDown](https://github.com/mixmark-io/turndown) library to convert HTML to Markdown. The entire app is contained in one line of HTML.

## Tech Stack

- [TurnDown](https://github.com/mixmark-io/turndown) via CDN
- Vanilla JavaScript
- Hosted via GitHub Pages
